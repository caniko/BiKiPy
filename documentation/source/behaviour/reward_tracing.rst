==============
Reward Tracing
==============
Reward tracing trials include the animal (1) being detected in the starting area; (2) leaving the start area; (3) entering the reward area.

On step 2, we start counting the distance and time elapsed to arrive at step 3—entering the reward area.

Start and reward perimeter
==========================
The start and reward perimeter shape is dependent on the specific design of the experiment. Any shape supported by BiKiPy is applicable to these attributes.

Cheeseboard
-----------
We define the starting area as a rectangle covering the protrusion from the cheeseboard area. The reward area is defined as a circular perimeter that covers the cheeseboard-well containing the experiment reward.
