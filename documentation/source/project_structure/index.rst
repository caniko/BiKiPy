=================
Project Structure
=================
There are many kinds of experiment designs. The data from these experiments requires a standard for storage; otherwise, each data structure would require its own reading strategy to be used with BiKiPy.

Each structure is named in a way that makes sense to the user. The Sequence structure should be used when each animal goes through a sequenced set of trials, such as: 0-Habituation => 1-Training => 2-Test.
